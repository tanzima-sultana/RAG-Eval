## Code style

- Write verbose, explicit code. Prefer clarity over brevity or cleverness.
- Do not use list/dict/set comprehensions. Use explicit `for` loops with `.append()` or explicit assignment.
- Do not use `map()`, `filter()`, or `functools.reduce()`. Use explicit loops instead.
- Do not write single-line conditionals, single-line loops, or chained one-liners. One statement per line.
- Name functions and variables descriptively enough that control flow is readable without comments.
- Standard library only. Do not add a third-party dependency without asking the user first.
- Write explicit comments for each method. Write what input it takes, what output it produces and what it does in plain simple manner.

## Environment setup

This project uses the `pyenv` virtualenv at `~/pyenv` (Python 3.10.12) for all Python version and dependency management. Do not use the system Python, and do not create a `venv`/`virtualenv` inside this repo. Never call `python`/`pip` against the system interpreter directly.

## Shell scripts

Any shell script added to this project (setup, run, test helpers) must follow the same pattern:
All commands below assume current working directory is the repo root (`rag-eval/`).

1. Activate the environment:

```bash
   source ~/pyenv/bin/activate
```

2. Set `PYTHONPATH` relative to the repo root:

```bash
   export PYTHONPATH="$(pwd)"          # if invoked from repo root
   export PYTHONPATH="$(dirname "$0")/.."  # if callable from elsewhere
```
## Project Structure

src/
   rag.py                  # CLI entry point for the entire pipeline

   l1_doc_processing/
      schema.py            # Defines the Document dataclass — the normalized record format every parsed document is converted into
      parser.py            # Abstract parser base class plus the parser registry lookup (maps doc type -> parser)
      parsers/
         pdf.py            # Extracts text from PDF files
      text_cleanup.py      # Cleans Document.text. Strips headers/footers, collapses repeated whitespace and blank lines
      metadata.py          # Extracts generic metadata from a document's raw bytes
      dedup.py             # Detects exact duplicates (hash) and near-duplicates (MinHash/LSH)
      doc_processing.py    # DocProcessing orchestrator 
      main.py              # CLI entry point — parses args and wires the pipeline
   
   l2_chunking/
      main.py              # CLI entry point for the chunking layer
      chunking.py          # Abstract chunking base class plus the strategy registry lookup (maps strategy name -> chunker)
      fixed.py             # Fixed-size chunking strategy
      sentence.py          # Sentence-aware chunking strategy
      semantic.py          # Semantic chunking strategy

tests/                # Test suite
data/
  raw/                # Raw input documents
  processed/          # Output of processed documents

log/
  log_doc_processing.txt    # Run log for doc processing
  log_test.txt              # Run log for test runs
  log.txt                   # General run log

common/
  constants.py          # Hardcoded project-wide constants
  dataset_config.py     # Dataset-related config — source URL, name, doc_type, content field, etc.
  identifiers.py        # Computes hashes for documents/records
  paths.py              # Computes file and directory paths used across the project

scripts/
  run.sh                    # Runs the entire pipeline end-to-end
  run_doc_processing.sh     # Runs only the l1_doc_processing layer
